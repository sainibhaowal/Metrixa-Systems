# Support

## Before asking for help

Read the relevant sections of [README.md](README.md),
[DATA_HANDLING.md](DATA_HANDLING.md), and [SECURITY.md](SECURITY.md). Confirm
that the issue can be reproduced with synthetic or redacted data.

## Where to ask

- Use a GitHub issue for reproducible bugs and documentation corrections.
- Use a discussion or feature request for general ideas and workflow questions.
- Use the private security process in [SECURITY.md](SECURITY.md) for
  vulnerabilities. Do not publish them in an issue.

Include the operating system, Python and Node versions, the command or route,
the smallest safe reproduction, and relevant logs with secrets removed.

Metrixa is an independent pilot. Public support does not include guarantees
about third-party providers, source-site availability, mailbox deliverability,
or the accuracy of generated lead data.
